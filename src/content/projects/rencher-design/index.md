*Sustainable Home Design & Lead Generation Platform — In Progress*

A full-stack lead generation platform for an off-grid home design consultancy. Prospective clients complete a guided intake experience capturing property location, lifestyle profile, and home parameters. The platform integrates public climate and solar APIs to run a multi-domain calculation engine — estimating solar array sizing, battery capacity, thermal envelope modeling, and budget range — producing an interactive results dashboard that drives consultation bookings.

**Tech stack:** .NET 8 Minimal APIs, React, Azure Container Apps, Azure SQL, Key Vault
